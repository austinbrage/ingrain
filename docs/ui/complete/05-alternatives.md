# Complete · Alternatives

Status: Draft

Big words for the end screens, drawn with the real glyphs of `tui_big_text` (the library the app uses). The exercise and the session are chosen: **A, DONE** and **C, SESSION DONE**, both in the `Sextant` size (3 rows). The module uses the same size, so what makes it stand out is the frame, the sparkles and the color of the module name, and not the size of the letters. The `Sextant` size needs a terminal font with the Unicode legacy computing blocks.
